# 自动对位中间图（诊断用）

这些图是排查 `car-repair-color.pdf` 为什么会自动对位失败的中间结果，由 `/tmp/mh-probe/viz.js`
生成（脚本在会话临时目录里，逻辑见 `docs/auto-extract-plan.md` 的 §4.5）：

- `sheet.png` — 总览：灰度 / 墨迹图 / 方向筛边缘 X,Y / 四张投影剖面 / 检出格线与真值对比
- `overlay.png` — 绿=检出的格线（pitch 108），洋红虚线=真值 60px 格线（同一起点）
- `ink.png` `edgeX.png` `edgeY.png` — 单张中间图

**结论**：这一页地图地面的瓷砖纹理是**轴对齐**的，方向筛对它无效；而且格线被家具/图标打断，
"要求连续贯穿"会丢掉真线（实测方向筛后有 5.2 万边缘像素，经过最小行程 128px 后只剩 4 列）。
投影类方法无法区分"格子线"与"瓷砖线"。因此**自动检测网格不再作为主路径**，
改用「框选地图外框 + 行列数」直接确定几何（见 plan 文档 §4.6）。
