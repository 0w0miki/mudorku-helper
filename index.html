Murdoku 助手
① 地图准备 选择人物以设置关联 · 悬停格子查看所在区域

怎么用

① 地图准备阶段

  1. 填好行 / 列后点「生成地图」。人物数量 = min(行, 列)。22 人以内最后一个固定是 V（前面 A、B、C…，中间字母跳过：6 人 = A B C D E V）；超过 22 人就接着 A–Z 顺序排、跳过 X（…U V W、…V W Y），超过 25 人用 AA、AB… 继续。
    重新生成只重建题面（区域 / 物品 / 关联 / 标记会清空），底图与网格对位、显示偏好都会保留，改行列不用重新导入对齐。
  2. 点「＋ 新建区域」→ 在棋盘上单击格子切换选中（按住拖动可连续刷选）→ 填名称 → 保存。区域必须四连通，外轮廓会自动加粗显示。一个格子只属于一个区域，重复选中的格子会从原区域移过来。
  3. 点「＋ 新建物品」→ 同样选格子 → 填名称 → 选择可占据（人可以放在这些格子上）或不可占据（人不能放上去，游玩阶段会固定标红色 ✕）。一个格子也只能放一个物品。
  4. 人物编号默认按 A–Z 跳过 X 生成；选中人物后点「改名」可以改成 1–4 个字符的任意编号（不能重复、不能含 X），棋盘上的圆形标记会自动缩小字号适配。
  5. 在「人物」里点选一个人物，然后用下拉框选用要关联的区域或物品（选中的即建立关联，默认正相关）。已关联的条目上，点标签可在正相关 / 负相关之间切换，点 × 取消关联。
  6. 关联只是相关性提示——用来在悬停时高亮、辅助推理，不是必须满足的规则，「检查」不会因为关联不符而报错。
  7. 列表里点色块可换颜色，点「编辑」可继续增删该区域/物品的格子。

底图对位（可选）

  • 「底图」卡片就在左边最上面（和地图设置挨着）→ 导入图片或 PDF，它会衬在网格下方（PDF 会渲染成位图，多页可选页）。
  • 勾上「对齐底图」后：拖动棋盘 = 移动网格；拖网格右下角手柄 = 等比缩放（左上角不动）；方向键微调 1px、Shift + 方向键 10px。
  • 「底图透明度 / 底图缩放」调节观感；对好后取消勾选即可继续画区域 / 物品。有底图时格子底色是半透明的，所以地图能透出来。
  • 底图缩放可以精调：滑块步长 0.1%，旁边的 − / + 每次 0.1%（按住 Shift 是 1%），右侧显示到一位小数；对不齐时用按钮或方向键慢慢逼近，别用鼠标拖滑块。
  • ✂ 裁切到网格：对好之后点它，底图会按网格外框（留一点边距）裁掉四周多余部分，画面上只剩题目本体。裁完图片和网格就绑定了——之后用顶栏 🔍 缩放时，格子、底图、网格偏移会一起等比变化，对好的位置不会散。裁切算一次可撤销的操作。

PDF 摘录悬浮窗（右侧）

  • 题目 PDF 里往往还有一页写着人物 / 物品的具体信息。右侧「PDF 摘录」面板可以把它截下来钉在右边，游玩时一边看题一边对照，不用来回翻页。
  • 摘录窗：拖矩形截取。每张卡片可用 − / + 缩放（50%–400%，点中间的百分比还原），放大后按住卡片拖动平移；卡片右侧的小图是导航缩略图，蓝框标出现在看的是哪一块，点一下或拖动即可跳转（内容没超出卡片时自动隐藏）。按住标题栏拖动调整顺序。卡片区自己滚动，PDF 缩略图可折叠把空间让给卡片；点左侧箭头标签收起整个面板。
  • 点「导入 PDF」选一份文件——和底图完全独立，可以是另一个 PDF，也可以和地图不在同一页。用 ◀ ▶ 翻页。
  • 在页面上拖一个矩形，松手就把它截成一张卡片钉在下面；可以截多张，每张右下角的 ✕ 单独删除，或点「清空卡片」全清。
  • 点面板左侧的箭头标签可以把面板收起来；收起后只剩一个窄标签，角标显示当前有几张卡片。卡片和折叠状态都会记在本地。

界面

  • 左侧面板宽度可调：拖侧栏与棋盘之间的竖条（最小 300px，双击还原）；聚焦竖条后可用 ← → 微调。

② 游玩阶段

左侧人物是紧凑网格：角标显示候选数，已确定的整格填成本人颜色并带 ✓；点格子切换当前人物，操作只显示当前这一个。人多也不会拉成长条。
左键若正处在「标 X」模式，点另一个人会自动切回「候选」（选人就是要标他的候选）；点当前人物自己则保持原模式。

底图的导入 / 对齐 / 透明度 / 显示隐藏都在准备阶段那张「底图」卡片里；游玩阶段不再重复放开关。

行统计在网格右边、列统计在网格下面，显示这一行/列都有谁的候选（实心＝已确定），鼠标在哪一格对应行列就点亮。行统计横排一行、列统计竖排一列；统计条会按内容自己变大把标签尽量显示全（字号随格子缩放），只有到上限还放不下才折成 +N；可在工具卡里关掉。
点统计里的某个人＝「这一行/列就是他的」：清掉这一行/列里其他人的候选，其余格子全部标 ✕（只留他自己的候选格），只占一次撤销。

  • 左键点一下＝给当前人物标注候选；再点一次取消。
  • 按住左键拖动＝连续标注一片格子（起点格决定方向：空白格开始是「加候选」，已有候选的格子开始是「擦除」）。整段拖动算一次撤销。
  • 右键＝切换该格的 ✕（表示这个格子不能放人）。也可以把左键模式切换成「标 X」，此时拖动可以连续标 X，并且不会长按放人。
  • 长按 0.7 秒→ 出现圆形进度条，走满后把当前人物确定在该格，并自动在同一行、同一列（除当前格）标上 ✕。仅在「左键＝候选」模式下有效。
  • 鼠标停在一个格子上 → 高亮它所在的区域。
  • 鼠标停在人物上（棋盘上的圆形标记、候选小标签，或左侧人物条）→ 高亮该人物关联的区域与物品（正相关绿色、负相关红色），并把他自己的候选格用本人颜色描边顶出来，同格里别人的候选会淡下去。
  • 左侧「检查」实时列出真正的规则冲突：同行同列、放在 ✕ 或不可占据物品上、无处可放、唯一候选撞车等，点问题可以定位到格子。

其他

  • 撤销 / 重做：⌘Z / ⇧⌘Z（Windows：Ctrl+Z / Ctrl+Y）。
  • 所有改动会自动保存在浏览器本地；用「导出 / 导入 JSON」备份或分享题目。
  • 顶栏 🔍 − 滑块 + 三件套都在调同一个「棋盘缩放」（每格显示的像素大小，22–72px）：− / + 按钮按 6px 步进、到极限自动禁用，也可以直接拖中间那条；大棋盘可以在棋盘区域滚动查看。
